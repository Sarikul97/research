## How to deploy on GitHub Pages

1. **Create a new repository** on GitHub named `<username>.github.io`
   (or any name, e.g. `academic-profile`).

2. **Upload all files** — maintain this folder structure:
   ```
   index.html
   css/style.css
   js/main.js
   assets/photo.jpg   ← add your photo here
   README.md
   ```

3. Go to **Settings → Pages → Branch: main → Save**.

4. Your site will be live at `https://<username>.github.io/<repo-name>/` within a minute.
